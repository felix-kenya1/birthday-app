Before first run:
1. Copy .env.example to .env.
2. Configure the local MySQL credentials.
3. Run composer install and php artisan key:generate.
4. Create birthday_surprise_db in phpMyAdmin.
5. Run php artisan migrate and php artisan storage:link.
6. Create an admin using php artisan birthday:make-admin "Site Administrator" admin@example.com.

This is a repaired source package, not a claim that live MySQL/browser tests have passed.
